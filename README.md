# Conciliador de Cobros de Exportación (Streamlit)

Esta aplicación réplica al 100% la lógica, cálculos y diseño de tu herramienta original de conciliación de exportaciones, adaptada para correr de forma nativa en **Streamlit** y ser desplegada en **GitHub / Streamlit Community Cloud** de manera totalmente gratuita.

## Cómo ejecutar localmente:

1. Instala Python (versión 3.9 o superior).
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta la aplicación:
   ```bash
   streamlit run app.py
   ```

## Cómo desplegar en Streamlit Cloud (Gratis):

1. Sube estos tres archivos (`app.py`, `requirements.txt`, `README.md`) a un repositorio público en **GitHub**.
2. Entra en [share.streamlit.io](https://share.streamlit.io/).
3. Haz clic en **New app**, selecciona tu repositorio, rama (`main`) y archivo principal (`app.py`).
4. Haz clic en **Deploy** ¡y listo!
